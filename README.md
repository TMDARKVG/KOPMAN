# KOPMAN

<p align="center">KOPMAN is Koperasi management. A modern warehouse management system for tracking inventory, managing incoming and outgoing goods, organizing storage locations, and monitoring stock movements in real time. Designed to improve inventory accuracy, streamline warehouse operations, and simplify stock control.</p>
